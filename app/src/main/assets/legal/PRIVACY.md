## 本地数据

应用将主题、外观、更新通道、自动检查更新和忽略版本等设置保存在本机。应用不要求注册账户，也不包含广告或使用行为统计服务。

运行日志保存在应用私有目录，用于定位错误和崩溃。日志有容量限制并会轮转；常见令牌、密码、Cookie 和授权信息会被脱敏。日志和诊断附件不参与应用的云备份或设备迁移；设置可能根据系统备份选项被备份和恢复。

## 检查更新和外部链接

检查更新会通过 HTTPS 请求 GitHub Releases。GitHub 会收到网络连接所需的信息，例如 IP 地址、应用名称和版本标识。检查更新不附带本地日志、账户凭据或设备唯一标识。可在设置中关闭启动时自动检查，或选择正式版 / 预发布版通道。

打开项目、发布、反馈或开发者链接会切换到其他应用或浏览器，相关服务将按其自身规则处理网络信息。

## 诊断导出

仅在你主动操作时生成诊断文件，其中包含应用版本、Android 版本、设备厂商和型号以及本地日志。文件不会自动上传。导出时由你在系统文件选择器中选择保存位置。脱敏不能保证识别所有个人信息，如需发送导出文件，请先检查内容。

应用缓存中的诊断附件按保留时间和数量清理。你另行保存或发送的副本由你和接收方管理。

## 数据控制

清除应用数据或卸载应用会删除本机设置和日志；已保存或发送到外部位置的文件需要单独删除。系统恢复备份时可能恢复设置。
